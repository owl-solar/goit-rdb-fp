# Фінальний проєкт: Аналіз інфекційних захворювань (Relational Databases)

## 📌 Опис проєкту
Цей проєкт присвячений роботі з реляційними базами даних та аналізу статистичних даних про інфекційні захворювання за допомогою SQL та Python (Jupyter Notebook, SQLite/PostgreSQL, SQLAlchemy).

---

## 🛠 Етапи виконання проєкту

1. **Завантаження та ініціалізація даних:**
   * Створено схему бази даних `pandemic`.
   * Імпортовано початкові дані з файлу `infectious_cases.csv` у базову таблицю.

2. **Нормалізація даних (3-тя нормальна форма - 3NF):**
   * Виділено таблицю унікальних країн/регіонів (`countries`) з полями `id`, `Entity`, `Code`.
   * Створено нормалізовану таблицю показників (`infectious_cases_normalized`), де замість текстових назв країн використовується зовнішній ключ `country_id`.

3. **Аналіз даних:**
   * Написано SQL-запити для розрахунку середнього, мінімального, максимального значення та суми для показника захворювань на сказ (`Number_rabies`) у розрізі регіонів.
   * Результати відсортовано за середнім значенням у порядку спадання (з обмеженням у 10 рядків).

4. **Робота з датами:**
   * За допомогою вбудованих SQL-функцій сформовано дати першого січня відповідного року, отримано поточну дату та обчислено різницю в роках.

5. **Створення власних функцій (Python / SQLite):**
   * Реалізовано функцію для розрахунку різниці в роках відносно поточної дати.
   * Реалізовано функцію для розрахунку середньої кількості захворювань за періоди (місяць — дільник 12, квартал — дільник 4, півріччя — дільник 2) із перевіркою на числові значення.
   * Інтегровано та протестовано обидві функції у SQL-запитах.
